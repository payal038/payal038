## Production Projects

### WanderlustAI — AI-Powered Travel Booking Platform

> Node.js · Express · MongoDB · OpenAI GPT-4o · AWS S3 · Passport.js · Nodemailer · Helmet.js

A full-stack travel platform deployed on Render with 180+ real Indian hotel listings across 6 curated categories.

| Feature | Implementation |
|---|---|
| **Agentic AI Trip Planner** | Multi-step autonomous pipeline → day-by-day itinerary · budget breakdown · packing list |
| **GPT-4o Smart Search** | Natural language → ranked, filtered, semantically relevant results |
| **AI Concierge** | Context-aware chatbot for location-specific travel advice |
| **Review Summariser** | GPT-4o aggregates and summarises guest reviews |
| **Booking System** | Live availability verification · overbooking prevention · host dashboard |
| **Security** | Helmet.js · HSTS · rate limiting · NoSQL injection sanitization · CORS |
| **Infrastructure** | AWS S3 (image storage) · MongoDB Atlas · Nodemailer (email notifications) |

### VideoCall — Real-Time Video Conferencing App

> React 19 · Vite · Material-UI · WebRTC · Socket.IO · Node.js · Express · MongoDB

A full-featured, Zoom-like video conferencing platform. Peer-to-peer media streams never touch the server — Socket.IO handles only signaling.

| Feature | Implementation |
|---|---|
| **P2P Video/Audio** | WebRTC peer connections · ICE/STUN negotiation |
| **Screen Sharing** | Native browser screen-capture API via WebRTC data channel |
| **Real-Time Signaling** | Socket.IO room management · offer/answer/ICE exchange |
| **In-Call Chat** | Persistent message history per meeting |
| **Auth & History** | JWT-based auth · meeting history tracked in MongoDB |

[![Live Demo](https://img.shields.io/badge/Live%20Demo-VideoCall-0070F3?style=flat-square&logo=vercel&logoColor=white)](https://video-call-nine-jet.vercel.app)
